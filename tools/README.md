# Tools folder

These are manual Arena utilities. They are not imported by the live runner.

- `README.md` is this folder map.
- `api.py` makes authenticated diagnostic GET requests to Arena paths only.
- `audit_foreign_play_data.py` summarizes a collector decision CSV before model fitting: family mixes, facing-a-bet fold rates, aggression frequencies, sizing, and suggested class weights. Read-only and offline.
- `reconcile_foreign_raw_data.py` compares each collection's cached inventory, downloaded replays, and derived CSV, then classifies every gap: inventoried replays with no body on disk, downloaded replays outside the CSV, and which of those actually hold an in-scope decision. It also re-verifies CSV checksums and cross-season key uniqueness. Read-only and offline; `--report` writes the JSON audit.
- `rebuild_foreign_corpus.py` completes a collection without rewriting it. `--fetch` resumes the missing public replay downloads; `--derive` writes a sibling `*.delta.csv` holding only the rows whose `(agent_id, table_id)` receipt pair the frozen CSV never received, using that file's exact header so the pair loads together without duplicates. `--agent-scope archive` also admits agent folders whose full paginated history is cached but whose manifest omitted them; agents holding only the old 50-hand sample are never added. `--dry-run` reports both phases and changes nothing.
- `evaluate_policies.py` runs the offline gauntlet: each policy against the calibrated archetypes and the permanent shover plus head-to-head duels, scored in BB/100 at arena-realistic 60bb depth by default (`--starting-stack`). `--ablate-sizing` reruns a candidate's action head with heuristic sizing; `--hybrid-min-advantage` evaluates an in-distribution, confidence-gated correction layer. Run with `python -m tools.evaluate_policies`.
- `promote_candidate.py` promotes a verified candidate to the approved live artifact (atomic `artifacts/approved.json` pointer) and rolls back. Requires `--reason`; never contacts Arena.
- `self_play_cycle.py` harvests a diverse diet from heuristic-v5 states by default (calibrated lineup, heads-up vs shover/station/nit, optional champion-only sparring). It replays every legal family for one selected decision per actor; `--counterfactual-rollouts` averages several stochastic continuations without adding duplicate target rows. Behavior-only data pretrains the shared trunk through a transient classifier, so it cannot write imitation logits into the persisted value head. Validation records a regret curve for hybrid confidence thresholds. Sizing training is opt-in with `--train-risk-head`; new value candidates otherwise use heuristic sizing. `--device cuda --batch-size 1024` moves vectorized fitting to CUDA while simulation stays on CPU. `--harvest-workers 0` runs the independent legs in one process each within the core count (`1`, the default, keeps them sequential); every leg is separately seeded, so the examples and their order are identical either way and only wall-clock changes -- measured 2.47x on a four-leg harvest. `--dry-run` validates every corpus and prints the session without simulating or training.
- `leave.py` asks Arena to remove the agent from the explicitly named competition; importing it has no side effects.
- `peek.py` prints the explicitly named competition's pending-action state; importing it has no side effects.
- `poll.py` waits for a sandbox submission and returns a failure code unless it succeeds.
- `submit.py` uploads a strategy file or bundle to a sandbox competition.
- `update_agent_profile.py` renames the agent and refreshes its public profile through `PATCH /agent/me`. Dry-run unless `--apply`; the public quote and description default to the owner-mandated `Hello`.

Arena-facing tools resolve credentials from `ARENA_CREDENTIALS` when it is set, otherwise from the repository's gitignored `.arena-credentials`, so routine commands need no environment setup. The tools never print the key. (`evaluate_policies.py`, `promote_candidate.py`, `reconcile_foreign_raw_data.py`, and `self_play_cycle.py` are offline and read no credentials at all. `rebuild_foreign_corpus.py` reads none either: its `--fetch` phase calls the same unauthenticated public replay endpoints as the collector.)
