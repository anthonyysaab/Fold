# Artifacts folder

Trained data and measurement records read by policy code and tools. Map
rewritten 2026-09-02. Nothing here deploys itself: the only pointer the live
runner follows is `approved.json`, and promotion is an owner act.

- `approved.json` — the atomic pointer to the approved live artifact, written only by `tools/promote_candidate.py` (structure and checksum validation; it does **not** enforce a gauntlet gate). `run_agent.py --learned` follows it and refreshes between hands. It points at **`candidate-v9-0003b`** (promoted 2026-09-01T23:48Z); its `previous` block records `candidate-v7-0001c` (promoted 2026-08-14), one `--rollback` away. `manifest_file` is written with POSIX separators so a pointer promoted on Windows resolves on a Linux host.
- `candidates/` — one validated manifest plus one checksummed JSON weights file per candidate. The v9 candidates are **untracked** as of 2026-09-02, like their gauntlets and datasets.
