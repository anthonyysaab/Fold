# Treys evaluator folder

This is a vendored subset of the MIT-licensed Treys poker evaluator. Its upstream filenames are intentionally unchanged.

- `README.md` is this folder map.
- `LICENSE` is the upstream MIT license.
- `__init__.py` exports the evaluator's public classes.
- `card.py` encodes, decodes, and displays playing cards.
- `deck.py` creates and shuffles a standard deck.
- `evaluator.py` scores five-to-seven-card poker hands.
- `lookup.py` builds the lookup tables used to rank hands quickly.
